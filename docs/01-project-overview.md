# 案件概要

| 項目 | 内容 |
|---|---|
| 開発開始日 | 2025-07-21 |
| ターゲット | 20歳以上のファミリー層 |

## 開発目的

小規模農家の収益向上を支援するため、生産者の「想い」や「こだわり」を丁寧に伝えられる商品ページと、高齢の生産者でも扱いやすいUI/UXを備えた管理画面を持つ、直販型ECサイトを開発。

## 使用技術

### 言語

- HTML5
- CSS3
- PHP 8.2.19

### フレームワーク

- Laravel 11.9

### ツール

- Nginx 1.27.0
- MySQL 8.0.37
- Docker
- phpMyAdmin
- MailHog

### その他

- UIの動的な部分はLivewireを使用予定

## 追加機能

- 農家さんはモバイルでの管理を望んでいる為、全てSP用デザインを作成する
- 資材管理（発送用化粧箱の在庫及び置き場所の管理）機能
