# UAT：管理者用ログイン

| 項目 | 内容 |
|---|---|
| 対象ルート | GET /admin/login、POST /admin/login、POST /admin/logout（AdminAuthController）、GET /admin（仮のトップ） |
| ブランチ | feat/admin-login |
| 根拠 | docs/03-page-list.md「管理者用ログインページ」、docs/04-feature-list.md「管理者機能一覧」1〜3、docs/07-basic-design.md「管理者機能」、docs/02-initial-settings.md「ログインについて」、Figma Admin「ログインページ」（130:2）・login-button（130:44） |
| 実施日 | 2026-11-03 |

ユーザーと決めた事項（2026-11-02）：

- 公開側の認証ページのレイアウト（layouts/auth）と部品を使う。PCはFigmaどおり、左に幅550pxのパネル（ロゴ・見出し「管理者用ログイン」・©Shioya farm）、右に白いカード（最大600px、角丸20px、影）のフォーム。背景はFigmaの灰色の斜めの図形を画像にした管理画面用の背景画像（storage/image/tool/admin-login-page-back-image.webp）を使う。公開側のログインの背景画像（login-page-back-image.webp）は使わない。
- 見出し「管理者用ログイン」はFigmaどおり黒（ink）。公開側の見出し（緑）とは変えて、管理画面だとわかるようにする。
- 「パスワードをお忘れの方」と会員登録の案内は出さない。
- ロゴ（しおや農園）はリンクにしない（押しても公開サイトへ移動しない）。管理者が公開サイトを見るのはログイン後なので、導線はログイン後の管理画面で検討する。公開側のログイン・会員登録のロゴは今までどおりトップへのリンク。
- パスワード欄には公開側と同じ「表示」切替を付ける。
- 「ログイン」ボタンは、地はFigmaどおりの緑（#60b04e）、ホバー・フォーカス時は濃い緑（#427835）＋影。文字は、通常時は黒（ink。白だとコントラスト不足のため）、ホバー・フォーカス時は白。
- SPは公開側のログインと同じ作り（全面に管理画面用の背景画像、ロゴと見出し → フォーム → © の順。入力欄とボタンの高さ44px以上）。
- 管理者は会員とは別のアカウント（admins テーブル）で、ログインも別。会員としてログインしていても管理画面には入れず、管理者のメールアドレスで公開側の /login からはログインできない。
- ログイン後は /admin へ移動する。このブランチの /admin は、見出しと「ログアウト」ボタンだけの仮のページ（トップページは次のブランチでFigmaから作る）。
- ログアウト・退会はLaravel標準どおりセッション全体を破棄する。同じブラウザで会員・管理者の両方にログインしていた場合、どちらでログアウトしても両方ログアウトされる（同時ログインは本番でまず起きないため分離しない。2026-11-03 変更）。
- 入力欄はFigmaどおりグレー系：縁とプレースホルダーは #acacac、「表示」の文字は #6b6b6b、フォーカス時の枠もグレー系（公開側の橙にしない）。管理画面は白・黒・グレーが基本色調（2026-11-03 追加）。
- ログイン画面を開いたまま時間がたったり、別の窓でログイン・ログアウトしたりして送信が無効（419）になったときは、エラーページではなくログイン画面に戻して「ページの有効期限が切れました。もう一度ログインしてください。」と案内する。メールアドレスは残す。公開側の /login も同じ。管理画面の「ログアウト」で起きたときは /admin に戻して「もう一度ログアウトしてください。」と案内する（2026-11-03 追加）。
- ログインの試行回数の制限・エラーの文言は公開側のログインと同じ。

管理者アカウント：admin@admin.com / admin1234（シーダーで登録済み）。会員は mypage-uat@example.com / password123 を使う（ログインできないときは tinker でそろえて結果に書く）。

| AC-17 | ログイン画面を開いた後に別の窓でログイン・ログアウトしてから送信すると（送信が無効になる場合）、エラーページではなく同じログイン画面に戻り、「ページの有効期限が切れました。もう一度ログインしてください。」と出る。メールアドレスは残り、もう一度送ればログインできる。/admin の「ログアウト」で同じことが起きたときは /admin に戻り「ページの有効期限が切れました。もう一度ログアウトしてください。」と出る |
