| 項目 | 内容 |
|---|---|
| 対象ルート | GET /cart（shop.cart）、商品詳細 GET /items/{item}（shop.items.show）の「カートに入れる」 |
| ブランチ | feat/cart |
| 根拠 | docs/03-page-list.md「商品詳細ページ」（カートに保存ボタン、カートはモーダルウィンドウ）「カートページ」、docs/04-feature-list.md「カートページ表示機能」「カート機能」、docs/07-basic-design.md（CartRequest：商品IDは必須・存在すること、数量は必須・整数・1以上10以下） |
| デザイン | Figma MCPの上限リセット（2026-11-01）まではフロントエンドを保留。ユーザーが渡したカートページの画面画像（PC版）を参考にした仮のBladeで実装し、モーダルも仮の見た目で作る。見た目は11月1日以降にFigmaの値で仕上げる |
| 実施日 | 2026-10-21 |

ユーザーと決めた事項：

- カートの中身はセッション（キー `cart`、`[商品ID => 数量]`）に保存する。テーブルは追加しない。ログアウトするとカートは空になる。
- 商品詳細の「カートに入れる」を押すとセッションに保存され、モーダルが表示される。モーダルには「カートに追加しました」のメッセージ、カートページへのリンク、商品一覧ページへのリンクがある。
- カートページへの導線は、ヘッダーの「カート」と、モーダルのカートページへのリンク。
- 「カートに入れる」と、カートページの数量変更・削除は Livewire で行い、ページを再読み込みしない。
- 「購入する」は購入機能ができるまでの仮リンク（`#`）。
- 「カートに入れる」は1回押すと1個追加する。すでにカートにある商品は数量を1増やす。最終的な数量はカートページで決めてもらう。
- 1商品の数量は10個まで（CartRequest と同じ）。10個入っている商品で「カートに入れる」を押すと、カートは変えず、モーダルに「この商品はカートに10個入っています。1つの商品は10個までです。」と表示する。
- モーダルのリンクの文言は「カートを見る」（/cart）と「買い物を続ける」（/items）。モーダルは右上の「×」やモーダルの外側を押しても閉じられる。

## 受け入れ条件

| ID | 条件 |
|---|---|
| AC-1 | ログイン中、商品詳細（予約限定でない商品）の「カートに入れる」を押すと、ページを移動せずにその商品が1個カートに追加され、「カートに追加しました」と「カートを見る」「買い物を続ける」のリンクがあるモーダルが表示される。すでにカートにある商品は数量が1増える |
| AC-2 | モーダルの「カートを見る」で /cart、「買い物を続ける」で /items へ遷移する。「×」またはモーダルの外側を押すとモーダルが閉じ、商品詳細ページのまま |
| AC-3 | カートに10個入っている商品で「カートに入れる」を押すと、数量は10のままで、モーダルに「この商品はカートに10個入っています。1つの商品は10個までです。」と表示される |
| AC-4 | ログイン中、商品一覧・商品詳細のヘッダーの「カート」を押すと /cart へ遷移する。タブのタイトルは「カート \| Shioya Farm」、見出しは「カートに入っている商品」。ヘッダーは「お知らせ」「しおや農園について」「マイページ」「ログアウト」（「カート」は出さない）。共通フッターがある |
| AC-5 | 未ログインで /cart を開くとログインページへ遷移し、ログインするとカートページに戻る |
| AC-6 | カートの各商品について、商品画像、「商品名 重さkg」（例：じゃがいも 2kg）、「単価円(税込)」、数量の入力欄と「個」、「単価×数量」の金額、「削除」ボタンが表示される。金額は3桁区切り |
| AC-7 | カートの下に「小計」として全商品の金額の合計が表示され、その横に「購入する」ボタン（仮リンク「#」）、下に「買い物を続ける」リンク（/items へ）がある |
| AC-8 | カートページで数量を1〜10の範囲で変更すると、ページを再読み込みせずにその商品の金額と小計が更新される。変更はセッションに保存され、開き直しても残る |
| AC-9 | カートページで数量を0、11、空欄、小数にすると、エラーメッセージ（「商品の数は1個以上にしてください」「商品の数は10個以下にしてください」「商品の数を入力してください」など）に「（数量は○個のままです）」を付けて表示され、入力欄は保存済みの数量に戻り、カートの数量と金額は変わらない |
| AC-10 | 「削除」を押すと、ページを再読み込みせずにその商品がカートから消え、小計が更新される。開き直しても消えたまま |
| AC-11 | カートが空のとき（最初から空、または全部削除したとき）は「カートに商品はありません」と表示され、商品の行・小計・「購入する」は出ず、「買い物を続ける」だけが表示される |
| AC-12 | ログアウトして再度ログインすると、カートは空になっている |
| AC-13 | SP（幅414px）では、モーダルとカートページが横スクロールなしで収まり、カートの数量・金額・削除が読める・押せる。「カートに入れる」「削除」「購入する」とモーダルのリンクの高さは44px以上 |
