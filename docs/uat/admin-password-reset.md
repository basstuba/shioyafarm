# UAT：管理者のパスワード再設定

| 項目 | 内容 |
|---|---|
| 対象ルート | GET /admin/forgot-password、POST /admin/forgot-password、GET /admin/reset-password/{token}、POST /admin/reset-password |
| ブランチ | feat/admin-password-reset |
| 根拠 | ユーザーと決めた事項（2026-11-02 に「管理者がパスワードを忘れたときにログインできなくなるため作る」、2026-11-03 に仕様を決定）。設計書・Figmaにはないため、公開側のパスワード再設定（docs/03-page-list.md「パスワード再設定メールの送信ページ」「新しいパスワードの設定ページ」、docs/uat/password-reset.md）と管理者用ログイン（docs/uat/admin-login.md）に合わせる |
| 実施日 | 2026-11-03 |

ユーザーと決めた事項（2026-11-03）：

- 流れ・文言・入力のルールは公開側のパスワード再設定と同じ。送信ページで、未登録のメールアドレス・1分以内の再送信でも同じ案内を出し、メールは送らない（管理者かどうかが分からないようにする）。リンクの有効期限は60分。パスワードは8文字以上・確認用と一致。
- 管理者用ログインのフォームの下に「パスワードをお忘れの方」のリンクを出す（管理者用ログインのブランチでは出さないとしていたもの）。
- 見た目は管理者用ログインと同じ（管理画面用の背景画像 admin-login-page-back-image.webp、見出しは黒、入力欄はグレー系、ボタンは緑の地に黒文字、ロゴはリンクにしない、案内の枠はグレー）。ただしパネルの位置はログイン画面と反対で、PCは左にフォーム・右にパネル（公開側の会員登録・パスワード再設定と同じ並び）。
- パネルにはロゴ・見出し・© だけを置き、ログインへ戻る案内（枠線のボタン）は置かない。ログインへ戻るリンクはフォームの下に文字リンクで出す。
- SPは管理者用ログインと同じ作り（全面に背景画像、ロゴと見出し → フォーム → © の順。入力欄とボタンの高さ44px以上）。
- 再設定後は /admin/login へ移動し、「パスワードを再設定しました。新しいパスワードでログインしてください。」を出す。
- メールは公開側と同じ書式。件名は「【しおや農園】管理画面のパスワード再設定のご案内」、宛名は管理者の名前「〇〇 様」。
- 管理者としてログイン中にこれらのページを開くと /admin へ移動する。
- 会員の再設定とは別の仕組みにする（会員のメールアドレスでは管理者の再設定メールは届かず、管理者のメールアドレスでは会員の再設定メールは届かない）。

管理者アカウント：パスワードを変えるシナリオがあるため、admin@admin.com は使わず、UAT用の管理者「UAT再設定管理者」（uat-admin-reset@example.com / oldpass123）を tinker で追加して使う。メールの確認は Mailpit（http://localhost:8025）で行う。
