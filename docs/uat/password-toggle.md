# UAT：パスワードの表示／非表示の切り替え

| 項目 | 内容 |
|---|---|
| 対象ルート | GET /login（login）、GET /register（register）、GET /reset-password/{token}（password.reset）、GET /mypage/edit（登録情報変更） |
| ブランチ | feat/password-toggle |
| 根拠 | ユーザーの要望（2026-11-02）。Figmaにデザインなし |
| 実施日 | 2026-11-02 |

ユーザーと決めた事項（2026-11-02）：

- パスワードの入力欄すべて（ログイン、会員登録の2つ、新しいパスワードの設定の2つ、登録情報変更の3つ＝パスワード・確認用パスワード・現在のパスワード）に、表示／非表示を切り替えるボタンを付ける。
- ボタンは入力欄の右端の内側に置く文字のボタン。伏せ字のときは「表示」、文字が見えているときは「非表示」。色はほかのリンクと同じ濃い茶色。タップ領域はSPで44px以上。入力した文字がボタンの下に隠れないよう、入力欄の右の余白を広げる。
- 欄ごとに別々に切り替わる（会員登録でパスワードを表示しても、確認用パスワードは伏せ字のまま）。
- ページを開き直したとき・送信してエラーで戻ったときは、伏せ字に戻る。
- 読み上げ・キーボードでも使えるようにする（Tabでボタンに移り、Enter・Spaceで切り替わる。状態は「表示」「非表示」の文言で読み上げに伝わる）。
- 切り替えは Livewire 同梱の Alpine.js で書く（素のJavaScriptは書かない）。パスワードをサーバーへ送らないよう、Livewire のコンポーネントにはしない。認証ページのレイアウトでも Livewire を読み込む。

## 受け入れ条件

| ID | 条件 |
|---|---|
| AC-1 | 対象の4ページの、すべてのパスワード欄の右端に「表示」ボタンがある。ほかの入力欄（メールアドレスなど）にはない |
| AC-2 | 「表示」を押すと入力した文字が見え、ボタンが「非表示」に変わる。「非表示」を押すと伏せ字に戻り、ボタンが「表示」に戻る。入力した内容は消えない |
| AC-3 | 欄ごとに別々に切り替わる |
| AC-4 | 文字が見えている状態で送信しても、伏せ字のときと同じように動く（ログインできる・エラーが出る） |
| AC-5 | 送信してエラーで戻ったときは、パスワード欄は空で伏せ字の状態になっている |
| AC-6 | キーボードだけで切り替えられる |
| AC-7 | SP（幅414px）で、ボタンが押しやすく（高さ44px以上）、長いパスワードを入れても文字がボタンに重ならず、横スクロールが出ない |

## シナリオ

ログインは uat-reset@example.com / newpass123、登録情報変更は mypage-uat@example.com / password123 を使う（ログインできないときは tinker でそろえて結果に書く）。登録情報変更では、パスワードを実際に変えない（エラーになる入力で確認する）。

### UAT後の修正（2026-11-02、メインセッション）

- UATの気になった点1（文言が「表示」「非表示」と変わるうえに aria-pressed も切り替わり、読み上げで「非表示、トグルボタン、オン」のように二重になる）を受け、aria-pressed を外した。WAI-ARIA の指針では、トグルボタンは「文言を固定して aria-pressed で状態を伝える」か「文言を変えて状態を伝える」のどちらか一方にする。今回は見た目と同じ文言で伝える後者にした。S-6 の「aria-pressed に出ている」は、この修正で「ボタンの文言が変わる」に読み替える。
- PCのボタンの高さ40px（入力欄と同じ）、長いパスワードは欄の中でスクロールする点は、そのままにする。

### レビュー後の修正（2026-11-02、/code-review medium）

- 表示のままフォームを送信すると、文字の欄のまま送られ、ブラウザのパスワード保存が効かなかったり入力履歴に平文で残ったりするおそれがあるため、送信のときに伏せ字へ戻すようにした。
- ブラウザの「戻る」でページが復元されると表示のまま戻ってくるため、復元時にも伏せ字へ戻すようにした。
- Edge が出すパスワード欄の目のアイコンが「表示」ボタンと重なるため、隠した。
- S-6 の期待結果を、aria-pressed ではなくボタンの文言が変わる形に直した。認証レイアウトの説明に、Livewire を読み込む理由を書いた。テストの説明の誤りを直し、Livewire の出力の細かい文言に依存しないようにした。
- 見送り：パスワード欄のない /forgot-password でも Livewire を読み込む件（ほかのページと同じファイルでキャッシュが効くため）、JavaScript が動かないときに入力欄の右の余白だけが残る件（影響が小さいため）。
- ブラウザで、送信時・復元時に伏せ字へ戻ることを確認。テスト904件成功。E2E（Stripe以外）12件成功。
