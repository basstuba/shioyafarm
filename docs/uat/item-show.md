## 受け入れ条件

| ID | 条件 |
|---|---|
| AC-1 | ログインしていなくても /items/{商品ID} を開くと商品詳細ページが表示される。タブのタイトルは「商品詳細 \| Shioya Farm」。ヘッダーのナビは商品一覧ページと同じ（未ログイン：「お知らせ」「しおや農園について」「ログイン」、ログイン中：「お知らせ」「しおや農園について」「カート」「マイページ」「ログアウト」）。共通フッターがある |
| AC-2 | ページには、商品画像、「商品名 重さkg」（例：じゃがいも 2kg）、商品説明文、「価格円(税込)」（価格は3桁区切り。例：1,320円(税込)）が表示される |
| AC-3 | ログイン中、通常の商品（予約限定でない商品）では「カートに入れる」「購入する」の2つのボタンが表示される。「予約する」ボタンは表示されない |
| AC-4 | ログイン中、予約限定の商品（北の恵みセット）では「予約する」ボタンだけが表示され、「カートに入れる」「購入する」は表示されない。画像には商品一覧と同じ「予約限定」のバッジが付く |
| AC-5 | 「カートに入れる」「購入する」「予約する」は、カート・購入・予約の機能ができるまでの仮のボタンとする（リンク先は「#」で、押してもページは移動せず、エラーにならない） |
| AC-6 | 未ログインのときは、「カートに入れる」「購入する」「予約する」のボタンは表示されず、代わりに「※ご購入の際は会員登録とログインをお願いします。」と「会員登録」ボタンが表示される。「会員登録」を押すと会員登録ページ（/register）へ遷移する |
| AC-7 | ページ下部に「商品一覧に戻る」のリンクがあり、押すと商品一覧ページ（/items）へ遷移する |
| AC-8 | 商品一覧ページの各商品の「詳しく見る」ボタンを押すと、その商品の詳細ページ（/items/{商品ID}）へ遷移する（これまでの仮リンク「#」を差し替える） |
| AC-9 | 存在しない商品ID（例：/items/99999）や数字でないID（例：/items/abc）を開くと、404ページが表示される |
| AC-10 | SP（幅414px）では、画像 → 商品名 → 説明文 → 価格 → ボタン（または会員登録の案内）→「商品一覧に戻る」の順に縦に並び、横スクロールが出ない。ボタンの高さは44px以上 |
