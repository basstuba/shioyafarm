## 受け入れ条件

| ID | 条件 |
|---|---|
| AC-1 | SP（幅768px未満）では、ヘッダーの右側に、よく使う項目と「メニュー」ボタン（三本線のアイコン＋「メニュー」の文字）だけが表示される。表示される項目は次のとおり。<br>・トップ・静的ページ（未ログイン）：オンラインショップ<br>・トップ・静的ページ（ログイン中）：オンラインショップ、マイページ<br>・ショップ（未ログイン）：ログイン<br>・ショップ（ログイン中）：カート、マイページ<br>・カート・購入手続き：マイページ |
| AC-2 | 「メニュー」ボタンを押すと、ヘッダーのすぐ下にメニューが開き、その下の画面は半透明の黒で暗くなる。メニューには、ヘッダーに出ていない残りの項目が縦に並ぶ。<br>・トップ・静的ページ（ログイン状態によらず）：お知らせ、しおや農園について<br>・ショップ（未ログイン）：お知らせ、しおや農園について<br>・ショップ（ログイン中）、カート・購入手続き：お知らせ、しおや農園について、ログアウト（ログアウトのアイコン付き） |
| AC-3 | メニューの各行は、アイコン・項目名・「＞」が横に並び、文字は16px、行の高さは56px程度で押しやすい。メニューが開いている間、「メニュー」ボタンは「×」のアイコンと「閉じる」の文字に変わる |
| AC-4 | 開いたメニューは、「閉じる」ボタン、暗くなった部分を押す、Escキー、のどれでも閉じる。閉じると「メニュー」ボタンの表示に戻る |
| AC-5 | メニューの項目を押すと、それぞれのリンク先へ移動する。トップページで「お知らせ」「しおや農園について」を押した場合は、メニューが閉じて、同じページのその位置までスクロールする |
| AC-6 | ショップ（ログイン中）でメニューの「ログアウト」を押すと、ログアウトされる（その後のヘッダーは未ログインの表示になる） |
| AC-7 | 幅320px・375px・414pxのどれでも、ヘッダーの項目は1行に収まり、ヘッダー（高さ70px）からはみ出さない。ページに横スクロールが出ない |
| AC-8 | PC・タブレット（幅768px以上）のヘッダーは今までと同じで、すべての項目が横に並び、「メニュー」ボタンは表示されない。SPでメニューを開いたまま画面幅を768px以上に広げても、メニューや暗い背景が残らない |
| AC-9 | キーボードでも操作できる。Tabキーで「メニュー」ボタンに移動してEnterで開閉でき、開いている間はメニューの項目にTabで移動できる。「メニュー」ボタンは、開閉の状態を読み上げソフトに伝える（aria-expanded が開くと true、閉じると false になる） |

- S-16 の備考（Tabの循環）：メニューを開いている間、Tab は「お知らせ」→「しおや農園について」→「メニュー（閉じる）」ボタン→「お知らせ」…と循環し、Shift+Tab は「お知らせ」→「メニュー」ボタン→「しおや農園について」…と逆向きに循環する。本文のリンクにはフォーカスが出ない。ログイン中の /items（項目が「お知らせ」「しおや農園について」「ログアウト」の3つ）でも、「ログアウト」の次の Tab で「メニュー」ボタンに戻り、そこから Shift+Tab で「ログアウト」に戻ることを確認した
- S-7 の補足（パネルが画面の高さを超える場合）：ログイン中の /items で、414×250 にして確認。パネルは max-height（画面の高さ − 70px = 180px）で止まり、パネル内が縦スクロールできる（scrollHeight 194px、スクロール可能量14px。scrollTop を大きくしても14pxで止まり、背後のページの scrollY は 0 のまま）。パネルの下端は画面下端（250px）に収まり、画面外にはみ出さない
- 前回から変わった点（確認した範囲では見た目・項目・並び順の変化なし）
  - メニューを開くとフォーカスが最初の項目に移る（S-6、S-16）
  - ×・暗い背景・Esc で閉じるとフォーカスが「メニュー」ボタンに戻る。リンクで移動した場合は戻らない（S-9、S-10）
  - 開いている間、Tab / Shift+Tab がボタンとパネルの項目の間で循環する（S-16）
  - 開いている間は背景のページがスクロールしない。閉じる、または768px以上に広げると解除される（S-9、S-15）
  - パネルは画面の高さを超えるとパネル内でスクロールする（S-7）
  - ナビ項目をBladeコンポーネント化しても、SP・PC、未ログイン・ログイン中のヘッダーとメニューの項目・並び・位置は前回と同じ
- 補足（NGではない気づき）
  - 「メニュー」ボタンの押せる範囲は約40×41pxで、目安の44pxにわずかに届かない（「オンラインショップ」「マイページ」等の既存リンクも高さ41px）。メニュー内の行は高さ56pxで十分。
  - SPでロゴと「しおや農園」の文字がヘッダー（高さ70px）の下にはみ出して見える（既知。今回の改修前からの見た目）。
  - 縦スクロールバーが常に表示されるブラウザ（今回のPlaywright）では、メニューを開いて背景のスクロールを止めると、スクロールバーが消えてページ幅が15px広がり、ヘッダーの項目が右に15px動く。スマホ実機（スクロールバーが重なって表示される）では起きない見込みだが、実機では未確認。
  - メニュー内「お知らせ」「しおや農園について」のリンク先は `http://localhost#news` のように `/` なしで出力されている（ブラウザ上では `/#news` に正しく移動する）。
  - 「マイページ」「カート」のリンク先は仮置きの # のため、移動先は確認していない。
  - カート・購入手続きのページはルートが無く、ブラウザでは確認していない（PHPUnitで確認する対象）。
