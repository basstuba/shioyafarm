## 受け入れ条件

| ID | 条件 |
|---|---|
| AC-1 | 未ログインで /register を開くと、会員登録ページが表示される。ページには「会員登録」の見出し、お名前（姓・名）・お住まいの地域（都道府県のセレクトボックス）・ご住所・電話番号・メールアドレス・パスワード・確認用パスワードの入力欄、「登録する」ボタン、ログインの案内と「ログイン」ボタン、サイト名（ロゴ）、©Shioya farm がある。タブのタイトルは「会員登録 \| Shioya Farm」 |
| AC-2 | ログインページと同じく、共通ヘッダー・共通フッターではなく、認証ページ用のヘッダー（サイト名）とフッター（©）が表示される。サイト名を押すとトップページへ遷移する |
| AC-3 | 「ログイン」ボタンを押すとログインページ（/login）へ遷移する |
| AC-4 | お住まいの地域のセレクトボックスは、初期表示が「選択してください」で、47都道府県（北海道〜沖縄県）から選べる |
| AC-5 | パスワード・確認用パスワードの入力内容は伏せ字で表示される |
| AC-6 | すべての項目を正しく入力して「登録する」を押すと、会員が登録され、ログイン状態でトップページへ遷移する。登録したメールアドレスとパスワードで、ログアウト後に再度ログインできる |
| AC-7 | 未入力の項目があると、該当する入力欄の近くに「〇〇を入力してください」（都道府県は「お住まいの地域を選択してください」）と表示され、登録されない |
| AC-8 | 電話番号がハイフン入り・数字以外を含む・9桁以下・12桁以上の場合は「電話番号はハイフンなしの半角数字10〜11桁で入力してください」と表示される |
| AC-9 | メールアドレスの形式が正しくない場合は「メールアドレスは有効なメールアドレス形式で入力してください」、31文字以上の場合は「メールアドレスは30文字以内で入力してください」、登録済みの場合は「このメールアドレスはすでに登録されています」と表示される |
| AC-10 | パスワードが8文字未満の場合は「パスワードは8文字以上で入力してください」、確認用パスワードと一致しない場合は「パスワードと確認用パスワードが一致しません」と表示される |
| AC-11 | 姓・名・ご住所が256文字以上の場合は「〇〇は255文字以内で入力してください」と表示される |
| AC-12 | 一覧にない都道府県の値を送信した場合（画面を改変した送信）は「お住まいの地域を一覧から選択してください」と表示され、登録されない |
| AC-13 | エラーで戻ったとき、パスワード・確認用パスワード以外の入力内容（選んだ都道府県を含む）は残っており、パスワード欄は空になっている |
| AC-14 | ログイン中に /register を開くと、トップページへ移動する |
| AC-15 | SP（幅414px）では、ログインページのSP版と同じく画面全体に背景画像が敷かれ、ロゴと「会員登録」の見出し → 登録フォーム → ログインの案内 → © の順に縦に並び、横スクロールが出ない。入力欄・セレクトボックス・ボタンの高さは44px以上、入力欄の文字は16px以上ある |
| AC-16 | PCで「登録する」ボタンにマウスを乗せると、背景が濃いオレンジ（#ff8800）になり影が付く。「ログイン」ボタンにマウスを乗せると、背景が茶色（#c0822f）・文字が白になり影が付く（ログインページのボタンと同じ演出）。Tabキーでフォーカスしたときも同じ見た目になる |
