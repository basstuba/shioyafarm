# UAT：管理画面の予約一覧

| 項目 | 内容 |
|---|---|

| ブランチ | feat/admin-reservation |
| 根拠 | docs/03-page-list.md「管理画面予約一覧ページ」、docs/07-basic-design.md、Figma 予約一覧（148:35）・予約詳細モーダル（152:231）、docs/uat/admin/admin-purchase.md のユーザーと決めた事項 |
| 実施日 | 2026-11-05 |

注文一覧から引き継ぐ事項：

- レイアウト（共通のヘッダー・フッター、サイドメニュー、中央のページタイトル）、ボタンの色、表の文字の大きさ（本文16px・モーダルの値14px）、表の幅（最大960px）、ページ送り、SPのカード形式は注文一覧と同じにする。Figmaの幅360pxのサイドメニューは使わない。
- 発送済みチェックは注文一覧と同じ形にする（表の1列目、検索の選択欄、押した瞬間に保存、発送済みの行の地は #d4d4d4）。管理者だけが見て、マイページ・メールには出さず、日時は持たない。

予約一覧で決める事項（案）：

- 文言の「注文」を「予約」に置き換える（予約管理番号・予約日・予約者）。
- 詳細モーダルは、Figmaの10項目。予約は1件1商品なので商品内訳は1行で、代引手数料はない。銀行振込のときは注文一覧と同じ形で支払いの案内を出し、口座情報は出さない。
- エクスポートは .xlsx。出力項目は docs/03 のとおり（予約管理番号・予約者・予約日・予約商品・商品重量・商品数量・配送先氏名・配送先住所・配送先電話番号）で、1予約1行。ファイル名は `予約一覧_YYYYMMDD.xlsx`（出力した日）。
- 発送済みの更新のルートは、設計書にないため POST /admin/reservations/update を足す。

## 受け入れ条件

| ID | 条件 |
|---|---|
| AC-1 | 未ログイン・会員としてのログインでは /admin/reservations、/admin/reservations/search を開けず、type=reservation の POST /admin/export もできない。どれも /admin/login へ移動する |
| AC-2 | 管理者としてログインすると、共通のヘッダー・フッター、サイドメニュー、中央のページタイトル「予約一覧」、検索欄、エクスポート、表、ページ送りが表示される。サイドメニューの「予約一覧」が太字とグレーの地で示される（検索結果のページでも同じ） |
| AC-3 | 表の列は発送済（チェックボックス）・予約管理番号・予約日（YYYY/MM/DD）・予約者（会員の姓名）・「詳細」で、新しい予約から順に1ページ10件表示される |
| AC-4 | 11件以上あるときはページ送りが表示され、ページを移動できる。10件以下のときはページ送りが出ない。存在しないページ番号を開くと最終ページが表示される |

| AC-8 | 検索後も入力した値が検索欄に残り、ページを移動しても検索条件が保たれる。「リセット」を押すと、検索欄が空になり全件の表示に戻る |
| AC-9 | 該当する予約がないときは、表の代わりに「該当する予約はありません。」と表示され、ページ送りは出ず、エクスポートは押せない |

| AC-13 | 銀行振込の予約では、予約時に顧客残高から支払い済みなら「予約時にお客様の残高からお支払い済みです」、それ以外は「振込先をご案内済みです。入金はStripeの管理画面でご確認ください」と表示される。口座情報は表示されない。クレジットカードの予約では表示されない。代引手数料はどの予約にも表示されない |
| AC-14 | エクスポートを押すと `予約一覧_YYYYMMDD.xlsx`（出力した日）がダウンロードされる。列は予約管理番号・予約者・予約日・予約商品・商品重量・商品数量・配送先氏名・配送先住所・配送先電話番号で、1予約1行、新しい予約から順に並ぶ。商品重量は「10kg」の形で、電話番号の先頭の0は消えない |

| AC-18 | 「発送済」のチェックを入れると、ページを移動せずにその場で保存され、再読み込みしても発送済みのままである。外すと未発送に戻る。これまでの予約と新しい予約は未発送で始まる |
| AC-19 | 保存できなかったときはチェックが元に戻り、保存できなかった旨の案内が表示される |
| AC-20 | 発送済みの行（SPはカード）は地が #d4d4d4 になり、チェックの操作と同時に切り替わる。未発送の行は白と #f9f9f9 の交互のままで、文字色は変わらない |
| AC-21 | チェックボックスは24pxで、押せる範囲は高さ44px以上である。読み上げで、どの予約のチェックかがわかる |
| AC-22 | 未ログイン・会員としてのログインでは発送済みを変更できない。存在しない予約は変更できず、他の予約も変わらない |
| AC-23 | マイページの予約履歴の表示は変わらず、発送済みにしてもメールは送られない。発送済みにしても、商品の予約可能数の残りは変わらない |
| AC-24 | SPでは検索欄が縦積みになり、表はカード形式になる。文字は16px以上（モーダルの値は14px）、ボタン・リンクは高さ44px以上で、横スクロールが出ない |
| AC-25 | ログアウトしたあとにブラウザの戻るボタンを押しても予約一覧の内容が表示されず、/admin/login へ移動する |
| AC-26 | トップページのカードとサイドメニューの「予約一覧」から /admin/reservations へ移動できる |
| AC-27 | 共通化のあとも、注文一覧の検索・詳細モーダル・発送済みチェック・エクスポート（ファイル名・列・検索条件の誤りのときの戻り先と文言）の動きは変わらない |
