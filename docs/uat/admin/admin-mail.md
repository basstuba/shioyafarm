# UAT：管理画面のメール作成・送信

| 項目 | 内容 |
|---|---|
| 対象ルート | GET /admin/mail/user/{user_id}（AdminMailController@createUserMail）、GET /admin/mail/inquiry/{inquiry_id}（AdminMailController@createInquiryMail）、POST /admin/mail/send（AdminMailController@send） |
| ブランチ | feat/admin-mail |
| 根拠 | docs/03-page-list.md「管理画面ユーザー一覧ページ」「管理画面お問い合わせ一覧ページ」、docs/04-feature-list.md（14・20・21）、docs/07-basic-design.md（ルート表・MailRequest）、Figma メール作成（183:2）、docs/uat/admin/admin-user.md・admin-inquiry.md のユーザー決定 |
| 実施日 | 2026-11-08 |

これまでの管理画面から引き継ぐ事項：

- レイアウト（共通のヘッダー・フッター、折りたためるサイドメニュー、中央のページタイトル）、入力欄の縁・プレースホルダーの色（#acacac）、Cache-Control: no-store、一覧に戻ったときの緑の案内（会員の削除・注文の取消と同じ形）。
- 確認モーダルは、会員の削除と同じ部品（x-admin-small-button など）を使う。

メール作成で決めた事項（11/8 ユーザー決定）：

- Figmaの縦書きのサイドバーは使わず、他の一覧と同じレイアウトにする。メール作成はサイドメニューに項目がないため、太字になる項目はない。
- ページタイトル「メール作成」と「送信する」ボタンは青（#2857ff。ボタンは白文字）。他の管理画面のタイトルの緑とは違う。
- カード（白・角丸30・影）の中に、送信先氏名・送信先メールアドレス（表示のみ）、メールタイトル（入力）、メール本文（入力）、「送信する」を縦に並べる（Figma 183:2）。プレースホルダーはタイトル「例：お問い合わせありがとうございます。」、本文「例：お問い合わせありがとうございました。」（Figmaの誤字「ありがとういございました」は直す）。
- 「一覧へ戻る」リンクを付ける（来た一覧に戻る）。
- 宛先は、会員なら会員登録のメールアドレス、お問い合わせならお問い合わせのメールアドレス。送信のフォームはメールアドレスを送らず、宛先の種類とIDだけを送る（任意の宛先には送れない）。退会済みの会員にも送れる。存在しない会員・お問い合わせは404。
- 検証：メールタイトルは必須・255文字以下、メール本文は必須・10,000文字以下（上限は設計書にない追加）。エラーのときは入力を残す。
- 送信の前に確認モーダル「メールを送信します。よろしいですか？」を出す（ボタンは「送信する」「キャンセル」）。二重送信はボタンを押せなくして防ぐ。
- 件名は、入力したタイトルの先頭に「【しおや農園】」を自動で付ける。フォームに「件名の先頭に【しおや農園】が付きます」と案内を出す。
- 本文はサンクスメールと同じ Markdown メールの枠（ヘッダー・フッター）に入れ、入力した文字はエスケープし、改行をそのまま出す。宛名・署名は自動で付けない。差出人は config('mail.from')。
- お問い合わせへの返信は、本文の下に元のお問い合わせ（問い合わせ日・内容）を引用として自動で付ける。
- 同期送信（キューは使わない）。送ったメールの履歴は保存しない。
- 送ったメールの控えを、農園のアドレス（config('mail.from.address')、既定は shioyafarm@example.com）に BCC で送る（11/8 ユーザー決定）。これが送信の記録になる。管理画面に送信履歴の一覧は作らない（余計な個人情報を持たないため）。
- 送信後は、来た一覧（会員一覧・お問い合わせ一覧。検索条件・ページも元のまま）に戻し、検索欄の下に「メールを送信しました。」を緑の文字で出す。メール作成ページを直接開いたときは、その一覧の1ページ目に戻す。
- お問い合わせへの返信を送っても、対応済みには自動でしない。
- 送信に失敗したときは、作成ページに入力を残して「メールを送信できませんでした。時間をおいて、もう一度お試しください。」を赤字で出し、ログに残す。
- 会員一覧の「メール送信」とお問い合わせ一覧の「返信」のリンクを route() に置き換える。

## 受け入れ条件

| ID | 条件 |
|---|---|
| AC-1 | 未ログイン・会員としてのログインでは、メール作成ページ（会員宛・お問い合わせ宛）を開けず、メールも送れず、/admin/login へ移動する |
| AC-2 | 会員一覧の「メール送信」から、その会員宛てのメール作成ページが開く。退会済みの会員の行からも開ける |
| AC-3 | お問い合わせ一覧の「返信」から、そのお問い合わせ宛てのメール作成ページが開く |
| AC-4 | メール作成ページには、共通のヘッダー・フッター、サイドメニュー、中央の青いページタイトル「メール作成」、白いカードの中に送信先氏名・送信先メールアドレス（表示のみ）、メールタイトル・メール本文の入力欄、件名に【しおや農園】が付く案内、青い「送信する」ボタン、「一覧へ戻る」リンクが表示される。サイドメニューに太字の項目はない |
| AC-5 | 送信先氏名・メールアドレスは、会員宛てなら会員の姓名と会員登録のメールアドレス、お問い合わせ宛てならお問い合わせの姓名とメールアドレスである |
| AC-6 | 存在しない会員・お問い合わせのメール作成ページは404になる |
| AC-7 | タイトル・本文を入れて「送信する」を押すと確認モーダル「メールを送信します。よろしいですか？」が出る。「キャンセル」・背景の押下・Escキーでは送らずに閉じ、入力は残る。モーダルの「送信する」で送信される |
| AC-8 | 送信すると、宛先に件名「【しおや農園】{入力したタイトル}」のメールが1通届く。差出人はしおや農園（shioyafarm@example.com）。本文は入力したとおりで、改行が保たれる。HTML版・テキスト版がある |
| AC-9 | お問い合わせへの返信では、本文の下に元のお問い合わせの問い合わせ日・内容が引用として付く。会員宛てには付かない |
| AC-10 | 送信後は来た一覧に戻り、検索欄の下に「メールを送信しました。」が緑の文字で表示される。一覧で検索・ページ移動をしてから来た場合は、その検索条件・ページのまま戻る。直接開いた場合は一覧の1ページ目に戻る |
| AC-11 | お問い合わせへの返信を送っても、そのお問い合わせの対応済みは変わらない |
| AC-12 | タイトルが空・256文字以上、本文が空・10,001文字以上のときは送られず、各欄の近くにエラーが表示され、入力した値が残る。タイトル255文字・本文10,000文字ちょうどは送れる |
| AC-13 | POSTで宛先の種類・IDを書き換えても、存在しない宛先には送れず（404またはエラー）、メールアドレスを直接指定して送ることはできない |
| AC-14 | 「送信する」を連続で押しても、メールは1通しか送られない |
| AC-15 | 送信に失敗したときは、作成ページに入力が残り、「メールを送信できませんでした。時間をおいて、もう一度お試しください。」が赤字で表示される |
| AC-16 | タイトル・本文、宛先の氏名、お問い合わせの内容に HTML の記号が含まれていても、画面・メールとも文字のまま表示される |
| AC-17 | 「一覧へ戻る」を押すと来た一覧（検索条件・ページも元のまま）に戻り、メールは送られない |
| AC-18 | SPではカードが画面幅に収まり、入力欄・ボタンは全幅、文字は16px以上、ボタン・リンクは高さ44px以上で、横スクロールが出ない。確認モーダルが画面からはみ出さない |
| AC-19 | ログアウトしたあとにブラウザの戻るボタンを押してもメール作成ページの内容が表示されず、/admin/login へ移動する |
| AC-20 | 会員一覧・お問い合わせ一覧の表示と動きは、リンク先のほかはこれまでと変わらない |
| AC-21 | 送ったメールの控えが、農園のアドレス（shioyafarm@example.com）に BCC で届く。お客様に届いたメールの宛先（To・CC）には農園のアドレスが出ない |
