# UAT：管理画面トップページ

| 項目 | 内容 |
|---|---|
| 対象ルート | GET /admin（admin.home）。ヘッダーのログアウトは POST /admin/logout（admin.logout） |
| ブランチ | feat/admin-home |
| 根拠 | docs/03-page-list.md「管理画面用ヘッダー」「管理画面用フッター」「管理画面トップページ」、docs/07-basic-design.md、Figma トップ（132:2）、ユーザーと決めた事項 |
| 実施日 | 2026-11-04 |

ユーザーと決めた事項（2026-11-04）：

- ヘッダー・フッターはトップページだけのもの。残りの管理画面は左のサイドメニューのデザインで、このブランチでは作らない。
- 「サイトを見る」はログアウトの左に置き、別タブで公開サイトのトップを開く。文字だけ（アイコンなし）で、文言に「別タブ」は付けない。
- ログアウト・「サイトを見る」はホバー時に、ログアウトのアイコンの色（緑 #60b04e）の下線を出す。
- 各ページへのリンクはホバー時に、そのカードの見出しの色の下線を出す。下線の太さと文字からの距離はログアウトと同じ（太さ 0.2em、距離 0.3em）。
- カードの見出しの色は、読みやすさのためにFigmaより濃くする（各種一覧 #427835、作成・登録 #8f5e1c）。
- 8つのリンクは設計書のURLで今つなぐ。リンク先の画面ができるまでは404になる。
- SPのヘッダーは2段（1段目タイトル、2段目に右寄せで「サイトを見る」「ログアウト」）、カードは縦積みで幅いっぱい・高さは中身に合わせる。リンクは18px・高さ44px以上。ヘッダーの「サイトを見る」「ログアウト」もSPでは18px。
- セッションが切れた状態でログアウトを押したときは、案内なしで /admin/login へ移動する（すでにログアウトした状態のため）。
