| ブランチ | feat/admin-purchase |
| 根拠 | docs/03-page-list.md「管理画面注文一覧ページ」、docs/07-basic-design.md、Figma 注文一覧（133:32）・注文詳細モーダル（152:184）、ワイヤーフレーム https://claude.ai/artifact/LRJ1TAFYWC7zMuKSKNbV5h 、ユーザーと決めた事項 |
| 実施日 | 2026-11-04 |

ユーザーと決めた事項（2026-11-04）：

- Figmaの幅360pxのサイドメニューはやめる。ヘッダー・フッターはトップページと共通にし、トップ以外の管理画面は、ヘッダーとフッターの間に細いサイドメニュー（幅200px）を置く。トップページにサイドメニューは付けない。
- ページタイトルは検索欄の上の中央に、横書き32px・#427835 で置く。
- サイドメニューは全体を畳める。畳むと幅56pxの帯になり、矢印と縦書きの「メニュー」だけを残す。ログイン直後は開いた状態で、その後は開閉の状態を覚えておく。
- サイドメニューのリンクは、トップページ、各種一覧（注文一覧・予約一覧・会員一覧・お問い合わせ一覧・お知らせ一覧・掲載商品一覧）、作成・登録（お知らせ作成・掲載商品登録）。表示中のページは太字とグレーの地で示す。未実装の画面へのリンクは、画面ができるまで404になる。
- 表の本文は16px、モーダルの値は14px にする（Figmaの12pxは小さいため）。
- 検索ボタンは緑 #60b04e の地にink文字、ホバー・フォーカスで #427835 の地に白文字。リセットは #acacac の地にink文字、ホバー・フォーカスで #6c6c6c の地に白文字＋影。エクスポートは #6c6c6c の地に白文字、ホバー・フォーカスで #424242＋影。
- 詳細モーダルはFigmaの10項目に加え、代金引換のときは「代引手数料」、銀行振込のときは注文時の支払いの案内を出す。口座情報は出さない。閉じ方は下の文字だけの「閉じる」・背景・Esc。
- エクスポートは .xlsx。検索中はその条件に合う全件を出力する（表示中のページだけではない）。1商品1行で、注文管理番号・注文者・配送先は全行に入れる。商品重量は「2kg」の形。ファイル名は `注文一覧_YYYYMMDD.xlsx`（出力した日）。
- SPは、ヘッダーをトップと同じ2段にして2段目の左に「メニュー」ボタンを置く。メニューの初期状態は閉じていて、ページを移ると閉じる。PCの開閉状態は引き継がない。検索欄は縦積み、表はカード形式、ボタン類は高さ44px以上。
- 銀行振込の案内は AC-13 の文言にする。注文後の入金はシステムで追跡していないため、「入金済み・未入金」は出さない。
- 検索結果が0件のときは、該当なしの文言を表示し、エクスポートのボタンを押せない状態にする。
- デザインにない追加機能として、注文の発送済みチェックを作る。Figmaのお問い合わせ一覧（157:2）の「対応済」と同じ形で、表の1列目に「発送済」、検索に「発送済 / 未発送」の選択欄を置く。
- チェックは押した瞬間に保存する（保存ボタンなし）。外せば未発送に戻る。保存できなかったときはチェックを戻して案内を出す。チェックボックスは24px、押せる範囲は高さ44px。
- 発送済みの行（SPはカード）は地を #d4d4d4 にして、チェックと連動させる。文字色は変えない。
- 発送済みは管理者だけが見る。マイページには出さず、メールも送らない。保存するのは発送済みかどうかだけ（日時は持たない）。エクスポートの列は増やさない（「未発送」で検索してエクスポートすれば発送リストになる）。
- 予約の発送済みは、予約一覧のブランチで同じ形で作る。
- ログアウト後に戻るボタンで管理画面が表示されないよう、管理者のログインが必要なページはブラウザに保存させない。


## 受け入れ条件

| ID | 条件 |
|---|---|
| AC-1 | 未ログイン・会員としてのログインでは /admin/purchase、/admin/purchase/search を開けず、POST /admin/export もできない。どれも /admin/login へ移動する |
| AC-2 | 管理者としてログインすると、共通のヘッダー・フッター、サイドメニュー、中央のページタイトル「注文一覧」、検索欄、エクスポート、表、ページ送りが表示される |
| AC-3 | 表の列は発送済（チェックボックス）・注文管理番号・注文日（YYYY/MM/DD）・注文者（会員の姓名）・「詳細」で、新しい注文から順に1ページ10件表示される |
| AC-4 | 11件以上あるときはページ送りが表示され、ページを移動できる。10件以下のときはページ送りが出ない |
| AC-5 | 注文日を入れて検索すると、その日（日本時間）の注文だけが表示される |
| AC-6 | 注文者名を入れて検索すると、姓名の部分一致で表示される。「山田太郎」「山田 太郎」「山田　太郎」「山田」「太郎」のどれでも見つかる |
| AC-7 | 注文日と注文者名の両方を入れると、両方に合う注文だけが表示される。どちらも空で検索すると全件が表示される |
| AC-8 | 検索後も入力した値が検索欄に残り、ページを移動しても検索条件が保たれる。「リセット」を押すと、検索欄が空になり全件の表示に戻る |
| AC-9 | 該当する注文がないときは、表の代わりに「該当する注文はありません。」と表示され、ページ送りは出ず、エクスポートは押せない |
| AC-10 | 注文日に日付でない値を送ると、検索欄の近くにエラーが表示され、画面は壊れない |
| AC-11 | 退会済みの会員の注文も一覧・検索・詳細・エクスポートに含まれる |
| AC-12 | 「詳細」を押すと、モーダルに注文管理番号・注文日・注文者・商品内訳（商品名と重量・単価・数量・小計）・送料・合計金額・配送先氏名・配送先住所・配送先電話番号・支払い方法が表示される。「閉じる」・背景の押下・Escキーで閉じる。内容が長いときはモーダルの中をスクロールできる |
| AC-13 | 代金引換の注文では「代引手数料」が表示される。銀行振込の注文では、注文時に顧客残高から支払い済みなら「注文時にお客様の残高からお支払い済みです」、それ以外は「振込先をご案内済みです。入金はStripeの管理画面でご確認ください」と表示される。口座情報は表示されない。クレジットカードの注文ではどちらも表示されない |
| AC-14 | エクスポートを押すと `注文一覧_YYYYMMDD.xlsx`（出力した日）がダウンロードされる。列は注文管理番号・注文者・注文日・注文商品・商品重量・商品数量・配送先氏名・配送先住所・配送先電話番号で、1商品1行、新しい注文から順に並ぶ。注文管理番号・注文者・配送先は全行に入る |
| AC-15 | 検索中にエクスポートすると、検索条件に合う注文が、表示中のページだけでなく全件出力される。検索していないときは全件が出力される |
| AC-16 | サイドメニューにトップページと8つのリンクが並び、表示中のページは太字とグレーの地で示される。リンク先は トップページ /admin、注文一覧 /admin/purchase、予約一覧 /admin/reservations、会員一覧 /admin/users、お問い合わせ一覧 /admin/inquiries、お知らせ一覧 /admin/notices、掲載商品一覧 /admin/items、お知らせ作成 /admin/notices/create、掲載商品登録 /admin/items/create である |
| AC-17 | PCでサイドメニューを畳むと、幅56pxの帯になり本文が広がる。もう一度押すと開く |
| AC-18 | PCでサイドメニューを畳むと、再読み込みやページを移ったあとも畳んだままになる。ログアウトしてログインし直すと開いた状態に戻る |
| AC-19 | トップページ（/admin）にサイドメニューは表示されず、ヘッダー・フッターの見た目は注文一覧と同じである。トップの「注文一覧」のリンクから注文一覧へ移動できる |
| AC-20 | ボタンの色とホバー・フォーカスの見た目が、ユーザーと決めた事項のとおりである |
| AC-21 | SPではヘッダーが2段になり、サイドメニューの代わりに「メニュー」ボタンが出る。メニューの初期状態は閉じていて、押すと開き、もう一度押すと閉じ、ページを移ると閉じる。PCで畳んだ状態でもSPの動きは同じ |
| AC-22 | SPでは検索欄が縦積みになり、表はカード形式になる。文字は16px以上（モーダルの値は14px）、ボタン・リンクは高さ44px以上で、横スクロールが出ない |
| AC-23 | ログアウトしたあとにブラウザの戻るボタンを押しても注文一覧の内容が表示されず、/admin/login へ移動する |
| AC-24 | 「発送済」のチェックを入れると、ページを移動せずにその場で保存され、再読み込みしても発送済みのままである。外すと未発送に戻る。これまでの注文と新しい注文は未発送で始まる |
| AC-25 | 保存できなかったときはチェックが元に戻り、保存できなかった旨の案内が表示される |
| AC-26 | 発送済みの行（SPはカード）は地が #d4d4d4 になり、チェックの操作と同時に切り替わる。未発送の行は白と #f9f9f9 の交互のままで、文字色は変わらない |
| AC-27 | チェックボックスは24pxで、押せる範囲は高さ44px以上である。読み上げで、どの注文のチェックかがわかる |
| AC-28 | 検索の「発送済 / 未発送」で、未発送だけ・発送済みだけに絞り込める。何も選ばないと両方が表示される。注文日・注文者名と組み合わせられ、ページを移動しても条件が保たれ、リセットで解除される |
| AC-29 | 「未発送」で検索してエクスポートすると、未発送の注文だけが出力される。エクスポートの列は AC-14 のままである |
| AC-30 | 未ログイン・会員としてのログインでは発送済みを変更できない。存在しない注文は変更できず、他の注文も変わらない |
| AC-31 | マイページの購入履歴の表示は変わらず、発送済みにしてもメールは送られない |
| AC-32 | PC・SPとも、メニューの開閉は約0.2秒で滑らかに動く。再読み込みやページ移動のときは動かず、保存された開閉の状態で表示される。OSで動きを減らす設定にしている場合は動かない |
