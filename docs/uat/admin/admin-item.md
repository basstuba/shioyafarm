# UAT：管理画面の掲載商品一覧・削除

| 項目 | 内容 |
|---|---|
| 対象ルート | GET /admin/items（admin.items.index）、DELETE /admin/items/delete（admin.items.delete） |
| ブランチ | feat/admin-item |
| 根拠 | docs/03-page-list.md「管理画面掲載商品一覧ページ」、docs/05-table-specification.md（items・purchase_history_items・reservations）、docs/07-basic-design.md、Figma 掲載商品一覧（166:25）・通常商品詳細モーダル（169:237）・予約限定商品詳細モーダル（169:282）・削除アラートモーダル（170:347）、docs/uat/admin/admin-user.md のユーザー決定 |
| 実施日 | 2026-11-08（アプリの表示はJSTで11/9） |

これまでの一覧ページから引き継ぐ事項：

- レイアウト（サイドメニュー、中央のページタイトル）、表の文字の大きさ（本文16px・モーダルの値14px）、表の幅、SPのカード表示、詳細モーダルの閉じ方（下の「閉じる」）、確認モーダルの形（会員一覧の削除と同じ）、Cache-Control: no-store。

掲載商品で決める事項：

- 登録・修正は次のブランチ（feat/admin-item-form）で作る。このブランチは一覧・詳細・削除と、過去の注文・予約の保護まで。
- 検索・ページ送りは付けない（商品が少ないため全件を表示する）。
- 並び順は、商品名ごとにまとめ、商品名のまとまりは最初に登録した順、その中は重さの順（2→5→10kg。同じ重さは登録順）。
- 表の列はFigmaどおり 商品名・商品重量（kg）・商品金額（円・税込）・「詳細」・「修正」・「削除」の6列。金額は3桁ごとにカンマを入れる（Figmaの「1320」→「1,320」）。
- 「修正」のリンク先は /admin/items/edit/{商品ID}（設計書の /admin/items/edit に商品IDを足す。メール作成と同じ形）。修正ページは次のブランチで作るため、このブランチでは押すと404になる。
- 詳細モーダルはFigmaの8項目（商品名・商品重量・商品金額・商品画像・商品紹介文・おすすめ商品掲載・通常/予約限定・予約可能数）。予約可能数は、通常の商品は「無」、予約限定で上限がないときは「上限なし」、上限があるときは「200（残り150）」のように残りも出す。
- 削除は論理削除（items に deleted_at を足す）。削除した商品は、公開側の商品一覧・トップのおすすめ・商品詳細・カート・購入・予約から消え、管理画面の一覧にも出ない。元に戻す機能は作らない。
- 削除の確認は、Figmaの削除アラートモーダルに「公開ページとカートから消えます。過去の注文・予約の記録は残ります。」を添える。
- 過去の注文・予約を守るため、注文明細（purchase_history_items）と予約（reservations）に、注文した時点の商品名と重さを保存する（既存のデータは今の商品の値で埋める）。マイページ・管理画面の詳細・エクスポート・サンクスメールは、保存した値で表示する。商品を削除・修正しても、過去の注文・予約の表示は変わらない。
- 商品と注文明細・予約の外部キーの cascadeOnDelete は、論理削除では働かないため残す（物理削除は作らない）。

## 受け入れ条件

| ID | 条件 |
|---|---|
| AC-1 | 未ログイン・会員としてのログインでは /admin/items を開けず、/admin/login へ移動する。削除のリクエストも受け付けない |
| AC-2 | 管理者としてログインすると、サイドメニュー、中央のページタイトル「掲載商品一覧」、表が表示される。サイドメニューとトップページの「掲載商品一覧」のリンクから開ける |
| AC-3 | 表の列は 商品名・商品重量（kg）・商品金額（円・税込）・「詳細」・「修正」・「削除」で、削除していない商品が全件表示される。検索欄とページ送りはない |
| AC-4 | 並び順は、商品名ごとにまとまり、まとまりは最初に登録した順、その中は重さの軽い順になる。あとから既存の商品名で別の重さを登録しても、その商品名のまとまりの中に入る |
| AC-5 | 金額は3桁ごとにカンマ区切りで表示される（例：1,320） |
| AC-6 | 掲載中の商品が1件もないときは、表の代わりに「掲載中の商品はありません。」と表示される |
| AC-7 | 「詳細」を押すと、モーダルに商品名・商品重量（kg）・商品金額（円・税込）・商品画像・商品紹介文・おすすめ商品掲載（掲載 / 未掲載）・通常/予約限定・予約可能数が表示され、「閉じる」で閉じる。紹介文は改行をそのまま表示し、長いときはモーダルの中をスクロールする |
| AC-8 | 予約可能数は、通常の商品は「無」、予約限定で上限がない商品は「上限なし」、上限がある商品は「上限（残り◯）」の形で表示される。残りは公開側の予約ページと同じ数になる |
| AC-9 | 「修正」のリンク先は /admin/items/edit/{商品ID} である（修正ページは次のブランチで作る） |
| AC-10 | 「削除」を押すと「{商品名} {重さ}kg を削除します。よろしいですか？」（例：「じゃがいも 5kg を削除します。よろしいですか？」）と「公開ページとカートから消えます。過去の注文・予約の記録は残ります。」の確認が表示される。「キャンセル」を押すと確認だけが閉じ、商品は削除されない |
| AC-11 | 確認で「削除する」を押すと商品が論理削除され、一覧に戻って表の上に「商品を削除しました。」が緑の文字（背景・枠なし）で表示され、その商品は一覧から消える |
| AC-12 | 削除済み・存在しない商品の削除をリクエストしても何も変わらず、一覧に戻って「商品が見つかりません。」が赤字で表示される |
| AC-13 | 削除した商品は、公開側の商品一覧・トップのおすすめに出ず、商品詳細・購入ページ・予約ページを直接開くと404になる。カートに入っていた場合はカートから消え、合計にも含まれない |
| AC-14 | 削除した商品を含む過去の注文・予約は、マイページの履歴・詳細、管理画面の注文一覧・予約一覧と詳細モーダル、エクスポートに、これまでどおり商品名・重さ・金額つきで表示される |
| AC-15 | 新しい注文・予約では、注文した時点の商品名と重さが保存される。あとで商品の名前・重さをDBで書き換えても、その注文・予約のマイページ・管理画面・エクスポートの表示は変わらない |
| AC-16 | このブランチより前の注文・予約も、マイグレーション後に商品名・重さが表示される（今の商品の値で埋まっている） |
| AC-17 | SPでは表がカード形式になる。文字は16px以上（モーダルの値は14px。確認モーダルのボタンの文字もSPは16px）、「詳細」「修正」「削除」は高さ44px以上で、横スクロールが出ない。詳細・確認モーダルが画面からはみ出さない |
| AC-18 | ログアウトしたあとにブラウザの戻るボタンを押しても掲載商品一覧の内容が表示されず、/admin/login へ移動する |
| AC-19 | 商品名・紹介文に HTML の記号が含まれていても、文字のまま表示される |
| AC-20 | 公開側の購入・予約・マイページ、管理画面の注文一覧・予約一覧・エクスポート・サンクスメールの表示と動きは、これまでと変わらない |
