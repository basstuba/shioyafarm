# UAT：管理画面の資材管理（資材一覧・追加・修正・削除）

| 項目 | 内容 |
|---|---|
| 対象ルート | GET /admin/materials（admin.materials.index）、POST /admin/materials/store（admin.materials.store）、POST /admin/materials/update（admin.materials.update）、DELETE /admin/materials/delete（admin.materials.delete）。トップ GET /admin（admin.home）に件数の表示を追加。すべて追加（設計書にない） |
| ブランチ | feat/admin-material |
| 根拠 | docs/01-project-overview.md「追加機能」の「資材管理（発送用化粧箱の在庫及び置き場所の管理）機能」、ユーザーと決めた事項（2026-11-12）、docs/uat/admin/admin-notice.md・admin-item.md・admin-home.md の決定 |
| 実施日 | 2026-11-13 |

ユーザーと決めた事項（2026-11-12）：

- 資材ごとに **資材名・在庫数・置き場所・基準値** を1行で持つ（テーブル `materials` を1つ追加）。同じ資材を複数の場所に分けて持つことはしない。入出庫の履歴は持たず、注文・予約の発送とも連動しない。
- 在庫数は、一覧の「修正」から開くモーダルで書き換える。モーダルでは4項目すべてを変えられる。資材の追加も同じ形のモーダルで行う（別ページは作らない）。
- 資材の削除あり。確認モーダルは掲載商品一覧・お知らせ一覧と同じ AdminDeleteConfirm を使う。削除は物理削除（資材を参照するテーブルはない）。
- 在庫数が基準値を **下回った**（在庫数 < 基準値）資材は一覧で強調する。管理画面トップにも件数を出し、資材一覧へリンクする。
- 検索・エクスポート・ページ送りは付けない（資材は数種類の想定）。

Claude の提案（このシナリオのOKで決定とする）：

- Figma に資材管理の画面はないため、新しくデザインは作らず、既存の管理画面の部品（サイドメニュー・中央のページタイトル・表とSPのカード・詳細モーダルの枠・入力欄の枠 #acacac・AdminDeleteConfirm）に合わせる。
- 一覧の表は 資材名・在庫数・置き場所・基準値・「修正」・「削除」の6列。並びは登録した順（古い順）。在庫数と基準値は右寄せの数字（3桁区切り）。
- 強調の形：在庫数が基準値を下回った行は、在庫数を赤字の太字にし、資材名の下に赤字で「残りわずか」を出す（色だけに頼らず文字でも示す）。基準値が0のときは強調しない（下回ることがないため）。
- 「資材を追加」ボタンは表の右上に置き、橙 #f0a13a の地に ink（#2e2e2e）の文字（掲載商品の「登録する」と同じ）。追加モーダルの「追加する」も同じ色。修正モーダルの「修正する」は青 #2857ff の地に白い文字（掲載商品・お知らせの修正と同じ）。どちらもホバー・フォーカスで色が濃くなり影がつく。
- モーダルのタイトルは「資材の追加」「資材の修正」。項目名は「資材名」「在庫数」「置き場所」「基準値」。基準値の下に補足「在庫数がこの数を下回ると「残りわずか」と表示します。0にすると表示しません。」。プレースホルダーは「例：化粧箱 5kg用」「例：作業小屋の棚の上段」。
- 入力の決まり：資材名は必須・50文字以内・同じ名前は登録できない。置き場所は必須・100文字以内。在庫数・基準値は必須・0〜99,999 の整数。全角の数字（例「４０」）も受け付けて半角として保存する（高齢の生産者のスマホ入力を考えて）。前後の空白は取り除く。
- 入力に誤りがあると、モーダルを開いたままの状態で一覧に戻り、項目ごとに赤字のエラーを出して入力を残す（エラー文は下の AC-10 のとおり）。
- 成功したらモーダルを閉じた一覧に戻り、表の上に緑の文字で「資材を追加しました。」「資材を修正しました。」「資材を削除しました。」。存在しない（削除済みの）資材の修正・削除は、一覧に戻って赤字で「資材が見つかりません。」。
- 削除の確認は「「{資材名}」を削除します。よろしいですか？」と補足「在庫数と置き場所の記録も消えます。」。ボタンは「削除する」「キャンセル」の順、最初のフォーカスは「キャンセル」。
- 資材が1件もないときは、表の代わりに「登録されている資材はありません。」。
- サイドメニューの一覧系の最後に「資材一覧」を追加する。トップの「各種一覧」カードの最後にも「資材一覧」を追加する。
- トップの件数：「残りわずか」の資材が1件以上あるとき、2枚のカードの上に赤字で「残りわずかの資材が {件数}件 あります。」と「資材一覧を見る」のリンクを出す。0件のときは何も出さない。
- 初期データ（シーダー `MaterialSeeder`）に化粧箱4件を、それぞれ別の置き場所で入れる（4種類・4か所は 2026-11-12 ユーザー指示。置き場所の名前・在庫数・基準値は仮の値）。1件は「残りわずか」になる値にして、強調とトップの件数をすぐ確認できるようにする：

  | 資材名 | 在庫数 | 置き場所 | 基準値 |
  |---|---|---|---|
  | 化粧箱 2kg用 | 120 | 作業小屋の棚 上段 | 30 |
  | 化粧箱 5kg用 | 80 | 作業小屋の棚 下段 | 20 |
  | 化粧箱 10kg用 | 15 | 倉庫1階 入口横 | 20 |
  | 化粧箱 15kg用 | 40 | 倉庫2階 奥 | 10 |
- 設計書 03・04・05・06（ER図の画像も）・07 に資材管理を追記する。
