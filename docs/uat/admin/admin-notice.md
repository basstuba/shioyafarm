これまでの管理画面から引き継ぐ事項：

- 一覧：レイアウト（サイドメニュー、中央のページタイトル）、検索・リセットの色、日付の検索欄、表の文字の大きさ（本文16px・モーダルの値14px）、ページ送り（1ページ10件）、SPのカード表示、詳細モーダルの閉じ方（下の「閉じる」・背景の押下・Escキー）、Cache-Control: no-store。お問い合わせ一覧と同じ部品を使う。
- 「修正」「削除」の列と削除の確認モーダル・結果の案内（緑の文字／赤字）は、掲載商品一覧と同じ形にする。
- 作成・修正ページ：カードの形（幅800px・角丸30・影）、入力欄の枠・プレースホルダーの色（#acacac）、「一覧へ戻る」のリンク、二重送信の防止、419（ページの有効期限切れ）のときは同じページに戻して入力を残す。掲載商品登録・修正と同じ。

お知らせで決める事項（修正・削除の追加、物理削除、トップを作成日にすることは 2026-11-07 ユーザー決定。文字数の上限と確認モーダルなしは 2026-11-11 ユーザー決定）：

- 設計書・Figma にない **修正と削除を追加する**（作成後の誤字を直せるようにするため）。ルートは掲載商品にそろえて GET /admin/notices/edit/{notice_id}・POST /admin/notices/update・DELETE /admin/notices/delete。修正ページは作成ページの形を流用する（Figma にはない）。削除は物理削除（お知らせを参照するテーブルはない）。
- **公開サイトのトップのお知らせは、作成日（created_at）の新しい順に5件、日付も作成日を出す**（これまでは更新日。修正しても並び順と日付が変わらないようにするため）。
- お知らせ内容は **2000文字以内**（設計書は必須・文字列のみ）。タイトルは設計書どおり必須・255文字以内。
- 「作成する」「修正する」を押したときの確認モーダルは出さない（掲載商品登録・修正と同じ）。
- 一覧の表は 作成日（YYYY/MM/DD、日本時間）・タイトル・「詳細」・「修正」・「削除」の5列（Figma の3列に「修正」「削除」を足す）。作成日の新しい順（同じ日時は新しく作った順）。長いタイトルは折り返す。
- 検索は作成日だけ（Figma・設計書どおり）。
- 詳細モーダルは 作成日・タイトル・本文 の3項目（Figma の項目名のまま）。本文の改行はそのまま表示し、長いときはモーダルの中をスクロールする。
- 作成ページ：タイトル「お知らせ作成」は #8f5e1c（Figma の橙の文字は読みにくいため。掲載商品登録と同じ）。項目名は「お知らせタイトル」「お知らせ内容」、プレースホルダーは Figma の「例：お知らせがあります！」「例：ECサイトで直接お買い求めいただけるようになりました！」。タイトル欄400px、内容欄584×169（PC）。「作成する」ボタンは橙 #f0a13a の地に ink（#2e2e2e）の文字、ホバー・フォーカスは #c0822f＋影（掲載商品登録の「登録する」と同じ。Figma の hover #ff8800＋白文字は使わない）。
- 修正ページ：タイトル「お知らせ修正」と「修正する」ボタンは青 #2857ff（ボタンは白文字、ホバー・フォーカスは #012ccb＋影。掲載商品修正と同じ）。今の値が入った状態で開く。
- 作成・修正・削除に成功したら一覧に戻り、表の上に緑の文字で「お知らせを作成しました。」「お知らせを修正しました。」「お知らせを削除しました。」。存在しない（削除済みの）お知らせの修正ページ・修正・削除は、一覧に戻って赤字で「お知らせが見つかりません。」。
- 削除の確認は「「{タイトル}」を削除します。よろしいですか？」と「公開サイトのトップからも消えます。」。ボタンは「削除する」「キャンセル」の順（掲載商品一覧と同じ。最初のフォーカスは「キャンセル」）。
- 該当するお知らせがない（0件・検索で該当なし）ときは、表の代わりに「該当するお知らせはありません。」。
- サイドメニュー：一覧・検索・修正ページでは「お知らせ一覧」、作成ページでは「お知らせ作成」が選択中の表示になる。リンクは route() に替える。
- 設計書（docs/03・04・07）に修正・削除と文字数の上限、トップの並び順を追記する。
