ユーザーと決めた事項：

- 対象は管理者だけ（全会員の個人情報・物理削除・取消を扱うため）。会員には付けない。
- 方式はメールのワンタイムコード（2026-11-07）。数字6桁、有効期限10分、5回間違えるとコードを無効にしてログインからやり直し。「コードを再送する」ボタンあり（前回の送信から1分たつまでは再送できない）（2026-11-11）。
- `.env` でオン・オフを切り替える。既定はオン、ポートフォリオの公開環境だけオフ（2026-11-07）。
- コード（ハッシュ化して保存）・有効期限・失敗回数は専用のテーブル admin_two_factor_codes に保存する。設計書 05・06・ER図に追加する（2026-11-11）。
- コード入力画面の見た目は管理者のパスワード再設定と同じ（PCは左にフォーム・右にパネル、管理画面用の背景画像、見出しは黒、入力欄はグレー系、ボタンは緑の地に黒文字、ロゴはリンクにしない）（2026-11-11）。
- 会員（users）の two_factor_* カラムと Fortify の二段階認証の設定はそのまま残し、設計書05の注記を「会員には二段階認証を付けない方針と理由」に書き換える（2026-11-11）。

管理者アカウント：admin@admin.com / admin1234。メールの確認は Mailpit（http://localhost:8025）で行う。`.env` の二段階認証はオン（既定）で実施する。
