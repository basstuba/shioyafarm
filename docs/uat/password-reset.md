## 受け入れ条件

| ID | 条件 |
|---|---|
| AC-1 | ログインページのフォーム内に「パスワードをお忘れの方」のリンクがあり、押すと再設定メールの送信ページ（/forgot-password）へ遷移する |
| AC-2 | 未ログインで /forgot-password を開くと、会員登録ページと同じレイアウト（PCは左に背景画像のパネル・右にフォーム。サイト名・©Shioya farm。共通ヘッダー・フッターなし）で、「パスワード再設定」の見出し、フォーム内に手順の案内文・メールアドレスの入力欄・「再設定メールを送信」ボタン、パネルにログインの案内と「ログイン」ボタン（/login へ）が表示される。タブのタイトルは「パスワード再設定 \| Shioya Farm」 |
| AC-3 | 登録済みのメールアドレスを入力して送信すると、同じページに「ご登録のメールアドレス宛てに、パスワード再設定用のメールをお送りしました。」と表示され、そのアドレスに再設定メールが1通届く |
| AC-4 | 未登録のメールアドレス・退会済み会員のメールアドレスを入力して送信した場合も、AC-3 と同じ案内が表示される。メールは送られない |
| AC-5 | 同じメールアドレスで1分以内にもう一度送信した場合も AC-3 と同じ案内が表示され、2通目のメールは送られない |
| AC-6 | メールアドレスが未入力の場合は「メールアドレスを入力してください」、形式が正しくない場合は「メールアドレスは有効なメールアドレス形式で入力してください」と入力欄の近くに表示され、メールは送られない |
| AC-7 | 再設定メールは差出人「しおや農園」、件名「【しおや農園】パスワード再設定のご案内」で、本文は日本語（会員名「〇〇 様」、再設定の手順、「パスワードを再設定する」ボタン、リンクの有効期限が60分であること、心当たりがなければメールを破棄してよいこと）。英語の定型文は含まれない |
| AC-8 | メールのボタン（リンク）を開くと、AC-2 と同じレイアウトで、「新しいパスワードの設定」の見出し、新しいパスワード・確認用パスワードの入力欄、「パスワードを再設定する」ボタンが表示される。入力内容は伏せ字で表示される。タブのタイトルは「新しいパスワードの設定 \| Shioya Farm」 |
| AC-9 | 新しいパスワードを正しく入力して送信すると、ログインページへ遷移し「パスワードを再設定しました。新しいパスワードでログインしてください。」と表示される。新しいパスワードでログインでき、古いパスワードではログインできない |
| AC-10 | パスワードが未入力の場合は「パスワードを入力してください」、8文字未満の場合は「パスワードは8文字以上で入力してください」、確認用パスワードと一致しない場合は「パスワードと確認用パスワードが一致しません」と表示され、パスワードは変わらない。エラーで戻ったときパスワード欄は空になっている |
| AC-11 | 一度使ったリンク・期限（60分）が切れたリンク・改ざんされたリンクで再設定しようとすると、「このリンクは無効か、有効期限が切れています。もう一度再設定メールを送信してください。」と表示され、パスワードは変わらない。再設定メールの送信ページへのリンクがある |
| AC-12 | ログイン中に /forgot-password や再設定のリンクを開くと、/login と同じくトップページへ移動する |
| AC-13 | SP（幅414px）で、送信ページ・再設定ページとも横スクロールが出ず、入力欄とボタンの高さが44px以上ある |

## シナリオ
