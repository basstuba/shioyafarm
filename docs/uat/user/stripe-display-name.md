# UAT：Stripe Checkout の店名

| 項目 | 内容 |
|---|---|
| 対象ルート | POST /purchase（購入の確定）・POST /reservation（予約の確定）のうち、支払方法がクレジットカードのとき作る Stripe Checkout Session |
| ブランチ | fix/stripe-display-name |
| 根拠 | 設計書にない修正（2026-11-13 ユーザー決定）。E2E（E-13）で、Stripe Checkout に店名ではなく Stripe アカウントのメールアドレスが出ていたため。Checkout Session 作成時の `branding_settings.display_name` で上書きする |
| 実施日 | 2026-11-14 |

## 受け入れ条件

| ID | 条件 |
|---|---|
| AC-1 | クレジットカードで購入するとき、Stripe Checkout の画面に店名「しおや農園」が出て、Stripe アカウントのメールアドレスは出ない |
| AC-2 | クレジットカードで予約するときも、AC-1 と同じく店名「しおや農園」が出る |
| AC-3 | 支払いの流れ（Checkout での支払い → 完了ページ、Checkout で「戻る」→ 購入・予約ページ）はこれまでどおり動く |
| AC-4 | 代金引換・銀行振込（Checkout を使わない支払方法）の動きは変わらない |

## 決めた事項

- 店名は config/services.php の stripe に `display_name`（「しおや農園」の固定値）で持ち、Checkout Session の作成時に `branding_settings.display_name` として渡す。`config('mail.from.name')` は環境変数（.env.example では APP_NAME）しだいで変わるので使わない。
- E2E の E-13・E-14 に、Checkout の画面に店名が出ることの確認を足す。

## シナリオ

Stripe はテストモード。カード番号は 4242 4242 4242 4242、有効期限は未来の日付、セキュリティコードは任意の3桁。

| ID | 対応AC | 画面幅 | 前提 | 手順 | 期待結果 |
|---|---|---|---|---|---|
| S-1 | AC-1, AC-3 | PC | 会員でログインし、カートに通常の商品が1件ある | カートから購入ページへ進み、支払方法「クレジットカード」で確定する。Stripe Checkout の画面を確認し、テストカードで支払う | Checkout の画面に「しおや農園」が出て、メールアドレスは出ない。支払い後、購入の完了ページに戻る |
| S-2 | AC-1 | SP | S-1 と同じ | S-1 と同じ手順で Checkout の画面まで進み、店名を確認する | 店名「しおや農園」が出て、メールアドレスは出ない |
| S-3 | AC-2, AC-3 | PC | 会員でログイン | 予約限定の商品から予約ページへ進み、支払方法「クレジットカード」で確定する。Checkout の画面で店名を確認し、「戻る」を押す | 店名「しおや農園」が出る。「戻る」で予約ページに戻る |
| S-4 | AC-4 | — | — | PHPUnit で確認する（Checkout Session の作成時に店名が渡ること、代金引換・銀行振込の既存テストが通ること）。UATではテストが通っていることを確認する | テストが通っている |
| S-5 | AC-1 | PC | — | E2E の E-13・E-14（`./e2e/run.sh stripe`）で、Checkout の画面に「しおや農園」が出ることも確かめる（メインセッションが実行） | 2件とも成功する |
