## 受け入れ条件

| ID | 条件 |
|---|---|
| AC-1 | ログインの有無にかかわらず /inquiry を開くと、お問い合わせフォームページが表示される。ページには共通ヘッダー・共通フッター、「お問い合わせフォーム」の見出し、お名前（姓・名）・メールアドレス・お問い合わせ内容の入力欄、「送信する」ボタンがある。タブのタイトルは「お問い合わせ \| Shioya Farm」 |
| AC-2 | トップページの「お問い合わせフォームへ」リンクから /inquiry へ遷移できる |
| AC-3 | すべての項目を正しく入力して「送信する」を押すと、お問い合わせが保存され（未対応の状態）、お問い合わせサンクスページ（/inquiry/thanks）へ遷移する |
| AC-4 | サンクスページには「Thank you !」、「お問い合わせありがとうございます。」、返信についての案内文、「ホームに戻る」リンクが表示され、共通ヘッダー・共通フッターは表示されない。「ホームに戻る」を押すとトップページへ遷移する |
| AC-5 | 送信せずに /inquiry/thanks を直接開いた場合や、サンクスページを再読み込みした場合は、お問い合わせフォームページへ移動する。再読み込みしてもお問い合わせが二重に保存されない |
| AC-6 | 未入力の項目があると、該当する入力欄の近くに「姓を入力してください」「名を入力してください」「メールアドレスを入力してください」「お問い合わせ内容を入力してください」が表示され、保存されない |
| AC-7 | メールアドレスの形式が正しくない場合は「メールアドレスは有効なメールアドレス形式で入力してください」、31文字以上の場合は「メールアドレスは30文字以内で入力してください」と表示され、保存されない |
| AC-8 | 姓・名が256文字以上の場合は「〇〇は255文字以内で入力してください」と表示され、保存されない |
| AC-9 | エラーで戻ったとき、入力した内容（お問い合わせ内容を含む）が残っている |
| AC-10 | 入力した内容に `<script>` などのHTMLが含まれていても、そのまま文字列として保存され、画面上でスクリプトとして実行されない |
| AC-11 | PCで「送信する」ボタンにマウスを乗せると、商品一覧ページの「会員登録」ボタンと同じく、背景が黄色（#ffdd5c）・文字が濃い茶色（#7a4f00）になり影が付く（枠線は消えるがボタンの大きさは変わらない）。Tabキーでフォーカスしたときも同じ見た目になる |
| AC-12 | SP（幅414px）では、フォームの白いカードが画面幅いっぱい（左右16pxの余白）に表示され、姓・名は横に2つ並び、メールアドレス・お問い合わせ内容の入力欄はカードの幅いっぱいに広がる。横スクロールが出ない。入力欄・「送信する」ボタンの高さは44px以上、入力欄の文字は16px以上ある |
| AC-13 | SPのサンクスページでは、「Thank you !」が画面幅に収まり、案内文は画面幅で折り返して表示され、横スクロールが出ない |

## シナリオ

送信するメールアドレスは、実施ごとに識別できるよう `uat-inquiry-<連番>@example.com` のように付ける（30文字以内）。
