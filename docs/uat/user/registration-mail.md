# UAT：会員登録完了メール

| 項目 | 内容 |
|---|---|
| 対象ルート | POST /register（register.store）※Fortify。登録の直後にメールを送る |
| ブランチ | feat/registration-mail |
| 根拠 | 設計書にない追加（2026-11-13 ユーザー決定）。形式は購入・予約のサンクスメール（docs/uat/user/thanks-mail.md）とパスワード再設定メール（docs/uat/user/password-reset.md）に合わせる |
| 実施日 | 2026-11-13（回数制限の追加後に再実施） |

## 受け入れ条件

| ID | 条件 |
|---|---|
| AC-1 | 会員登録が成功すると、登録したメールアドレス宛に会員登録完了メールが1通届く。差出人は config('mail.from')（しおや農園 / shioyafarm@example.com）、件名は「【しおや農園】会員登録ありがとうございます」 |
| AC-2 | 本文は Markdown メール（HTML版とテキスト版）で、サンクスメールと同じヘッダー・フッター・色。上から「〇〇 〇〇 様」（姓 名）→ 登録のお礼 → 「■ ご登録内容」（お名前・メールアドレス）→ マイページで登録情報の変更・退会ができる案内 → マイページへのボタン（/mypage）→ 心当たりがない場合の案内（お問い合わせフォームから連絡）→ 送信専用の案内とお問い合わせページのURL → 署名（差出人の名前・メールアドレス）の順 |
| AC-3 | 本文にパスワード・住所・電話番号は載らない |
| AC-4 | 入力エラーで登録されなかったときは、メールは送られない |
| AC-5 | メールの送信に失敗しても、会員登録は成立し、ログイン状態でトップ（登録後の遷移先）へ遷移する。失敗はログに残る |
| AC-6 | 登録後の画面遷移はメールサーバーの応答を待たない（サンクスメールと同じく、レスポンスの後に同期送信する。キューは使わない） |
| AC-7 | 姓・名に HTML のタグ（例：`<b>太</b>`）を入れて登録しても、メールではタグとして解釈されず、そのままの文字で表示される |

## シナリオ

メールは Mailpit（http://localhost:8025）で確認する。新規登録するメールアドレスは、実施ごとに重ならないよう `uat-regmail-<連番>@example.com` のように付ける（30文字以内）。
