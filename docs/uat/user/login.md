## 受け入れ条件

| ID | 条件 |
|---|---|
| AC-1 | 未ログインで /login を開くと、ログインページが表示される。ページには、メールアドレスとパスワードの入力欄、ログインボタン、「ログイン」の見出し、会員登録の案内と「会員登録」ボタン、サイト名（ロゴ）、©Shioya farm がある |
| AC-2 | ログインページには共通ヘッダー・共通フッターではなく、認証ページ用のヘッダー（サイト名）とフッター（©）が表示される |
| AC-3 | サイト名（ロゴ）を押すとトップページへ遷移する |
| AC-4 | 「会員登録」ボタンのリンク先は会員登録ページ（/register）である（会員登録ページ自体は別の作業で実装する） |
| AC-5 | パスワードの入力内容は伏せ字で表示される |
| AC-6 | 登録済みのメールアドレスとパスワードでログインすると、トップページへ遷移し、ログイン状態になる |
| AC-7 | メールアドレスが未入力の場合は「メールアドレスを入力してください」、形式が正しくない場合は「メールアドレスは有効なメールアドレス形式で入力してください」、パスワードが未入力の場合は「パスワードを入力してください」と、該当する入力欄の近くに表示される |
| AC-8 | メールアドレスとパスワードの組み合わせが正しくない場合は「メールアドレスまたはパスワードが正しくありません」と表示され、ログインしない |
| AC-9 | エラーで戻ったとき、入力したメールアドレスは残っており、パスワードは空になっている |
| AC-10 | 同じメールアドレスで1分間に5回続けてログインに失敗すると、6回目以降はしばらく待つよう日本語のメッセージが表示され、ログインできない |
| AC-11 | ログイン中に /login を開くと、トップページへ移動する |
| AC-12 | ログイン中にログアウトすると、ログアウト状態になりトップページへ遷移する。ログアウト後に /login を開くとログインページが表示される |
| AC-13 | SP（幅414px）では、画面全体に背景画像が敷かれ、ロゴと見出し → ログインフォーム → 会員登録の案内 → © の順に縦に並び、横スクロールが出ない。入力欄とボタンの高さは44px以上ある |
| AC-14 | PCでログインボタンにマウスを乗せると、背景が濃いオレンジ（#ff8800）になり影が付く。会員登録ボタンにマウスを乗せると、背景が茶色（#c0822f）・文字が白になり影が付く。Tabキーでフォーカスしたときも同じ見た目になる |
| AC-15 | スマホでページをピンチして拡大できる |
